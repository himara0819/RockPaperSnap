# RockPaperSnap 🎮

## Interactive Rock Paper Scissors Game

RockPaperSnap is a mobile application developed using **React Native and Expo** as part of the Mobile Application Development practical tutorial.

The application allows users to play Rock Paper Scissors against the computer, view game results, and track their scores.

## Features

- **Play Game:** Play Rock Paper Scissors against the computer.
- **Random Computer Selection:** The computer randomly selects Rock, Paper, or Scissors.
- **Scoreboard:** Tracks wins, draws, and losses.
- **Game Results:** Displays the outcome of each round.
- **Reset Game:** Resets the scoreboard and game state.
- **Rules Screen:** Displays the rules of Rock Paper Scissors.
- **Tab Navigation:** Navigate between Play Game and Rules screens.
- **Splash Screen:** Displays an introductory screen when launching the application.

## Technologies Used

- React Native
- Expo

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd RockPaperSnap
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the Expo development server

```bash
npx expo start
```

### 5. Run on a mobile device

Install Expo Go on your Android or iOS device and scan the QR code generated by the development server.

## How to Play

1. Open the Play Game screen.
2. Choose Rock, Paper, or Scissors.
3. The computer randomly selects its weapon.
4. The winner is determined according to the game rules.
5. View the result and updated scoreboard.
6. Use Reset Game to start a new scoreboard.

## Game Rules

- Rock crushes Scissors.
- Scissors cuts Paper.
- Paper covers Rock.
- Choosing the same weapon results in a draw.
